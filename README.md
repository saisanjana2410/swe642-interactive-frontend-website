# Interactive Front-end Website

## Overview
This project is an interactive front-end website developed using HTML5, CSS3, Bootstrap, and JavaScript. It extends a static website into a dynamic, user-friendly web application by incorporating client-side interactivity, data validation, cookies, and asynchronous data loading.

## Features
- Responsive user interface built with Bootstrap
- Navigation bar with dynamic content switching
- Cookie-based personalized greeting with time-of-day detection
- Client-side form validation with consolidated error messages
- Automatic calculation of average and maximum values from user input
- Ajax and JSON-based zipcode lookup to auto-populate city and state
- Improved user experience through event-driven JavaScript handling

## Technologies Used
- HTML5
- CSS3
- Bootstrap
- JavaScript (ES6)
- Ajax
- JSON

## Application Highlights
- Uses `onblur` and `onclick` event handling
- Implements browser cookies with expiration handling
- Performs client-side data parsing and validation
- Loads structured data asynchronously using Ajax

## Deployment
The application is deployed as a static website using AWS S3.
